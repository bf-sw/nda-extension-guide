NDA 기안 결재선 연결

배포 상태·사용 안내

바디프랜드 NDA 관리 시스템의 기안 제목·결재선·참조자와 현재 프로젝트의 NDA 작성본·법무의견서를 새 워크쓰루 기안 화면에 준비합니다.

바디프랜드 내부 업무용 기능입니다. NDA 관리 권한과 워크쓰루 포탈 로그인이 필요하며, 확장 프로그램 설치만으로 사내 정보에 접근할 수는 없습니다.

현재 배포 상태

웨일 게시 확인: 2026년 10월 29일 · 게시 버전 1.0.12

1.0.12는 편집기 내부 프레임의 준비 상태를 확인하도록 보완한 버전입니다. 이전 버전을 쓰고 있다면 웨일 스토어에서 업데이트한 뒤 NDA 페이지를 새로고침해야 기안 자동화를 시작할 수 있습니다.

  • 웨일 스토어: 게시 완료 — 웨일 스토어에서 무료 설치. 압축 해제나 개발자 모드는 필요 없습니다.
  • 엣지 스토어: 1.0.12 게시 완료 — 엣지 스토어에서 무료 설치. 2026년 10월 29일 게시를 확인했습니다.
  • 크롬: 연결 지원 · 스토어 미등록 — 크롬용 배포를 준비 중입니다. 웨일 스토어 링크로 크롬에 설치할 수는 없습니다.

설치하고 연결하기

NDA의 설치 안내는 웨일·엣지·크롬의 배포 상태와 현재 브라우저의 연결 상태를 각각 보여줍니다. 현재 설치 가능한 브라우저를 선택하고, NDA와 포탈은 같은 브라우저·프로필에서 사용해 주세요.

스토어 링크는 현재 브라우저의 새 탭으로 열립니다. 웨일이 자동 설치되거나 실행되지는 않습니다. 웨일이 없다면 공식 다운로드 페이지에서 설치한 뒤 웨일로 NDA를 열어 주세요. 엣지 사용자는 엣지 스토어 링크를 엣지 브라우저에서 열어 설치하세요.

  1. 사용할 브라우저에서 해당 스토어 링크를 엽니다. 웨일은 ‘추가하기’, 엣지는 ‘다운로드’ 또는 ‘받기’를 누르고 확장 추가를 확인합니다.
  2. 설치한 브라우저의 같은 프로필에서 NDA 관리 시스템으로 돌아와 ‘연결 다시 확인’을 눌러 새로고침하고 연결 상태를 확인합니다.
  3. 진행 과정의 4단계에서 ‘기안 작성하기’를 누르고, 제목을 확인하거나 수정한 뒤 ‘기안 자동화 시작’을 누릅니다.
  4. 새 포탈 창에서 필요하면 직접 로그인하고 자동 준비가 끝날 때까지 원래 NDA 탭을 열어 둡니다.
  5. 제목·결재선·참조자·첨부파일을 확인한 뒤 본문 작성과 나머지 처리를 직접 진행합니다.

업로드 시작·임시저장·결재 요청은 자동 실행하지 않습니다.

크롬에서 사용하려면

같은 확장 코드를 크롬에서도 사용하도록 구성되어 있습니다. 이미 설치된 확장이 응답하면 NDA 안내에 ‘설치·연결 완료’와 사용 중인 버전이 표시됩니다. 웨일의 설치 상태는 크롬에 공유되지 않습니다.

새로 설치할 직원용 크롬 배포 경로는 아직 준비 중입니다. 스토어 게시 또는 회사 관리 정책을 통한 배포가 확인되면 안내합니다. 회사 정책으로 폴더 설치가 막힌 경우 임의로 우회하지 말고 사내 브라우저 관리 담당자에게 확인해 주세요.

기존 설치본과 중복 설치 확인

기존 스토어 설치본은 삭제하지 않고 업데이트하세요. 1.0.12보다 낮은 버전이 표시되면 진행 중인 기안을 마친 뒤 웨일 스토어의 ‘업데이트’를 누르고 NDA 페이지를 새로고침합니다. 1.0.12로 연결되면 바로 사용할 수 있습니다.

폴더로 직접 설치했거나 삭제된 예전 스토어 등록의 설치본을 사용한다면 진행 중인 기안을 마친 뒤 웨일 확장앱 목록에서 이전 설치본을 삭제하고 현재 스토어에서 설치하세요. 스토어 개발자센터의 등록은 삭제하지 마세요.

‘설치 상태 확인 필요’는 이전 버전의 응답만 감지되어 현재 설치 상태를 확정할 수 없다는 뜻입니다. 삭제·비활성화 후에는 NDA 페이지를 새로고침하세요. 스토어 설치본을 삭제했어도 같은 이름의 직접 설치본이 켜져 있으면 계속 응답할 수 있습니다.

연결이 안 될 때

  • 확장이 현재 브라우저·프로필에서 켜져 있는지 확인한 뒤 NDA 페이지의 ‘연결 다시 확인’을 눌러 새로고침합니다.
  • 회사 정책으로 설치나 사이트 접근이 차단되면 사내 브라우저 관리 담당자에게 확인합니다.
  • 직원을 확정하지 못하거나 입력 중 오류가 발생하면 표시된 안내를 확인합니다. 설정을 정정한 뒤 NDA에서 새 작업을 시작합니다.
  • 포탈 창을 실수로 닫았다면 NDA의 ‘기안 자동화 시작’을 다시 누릅니다. 이전 창의 미저장 내용은 새 창으로 옮겨지지 않습니다.

지원 문의

사내 NDA 관리 담당자 또는 AI솔루션팀으로 문의해 주세요. 사용 브라우저·확장 버전·오류 문구를 함께 알려주면 확인에 도움이 됩니다. 문의에 비밀번호나 계약 문서 원문을 넣을 필요는 없습니다.
