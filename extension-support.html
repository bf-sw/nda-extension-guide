NDA 기안 결재선 연결

배포 상태·사용 안내

바디프랜드 NDA 관리 시스템의 기안 제목·결재선·참조자와 현재 프로젝트의 NDA 작성본·법무의견서를 새 워크쓰루 기안 화면에 준비합니다.

바디프랜드 내부 업무용 기능입니다. NDA 관리 권한과 워크쓰루 포탈 로그인이 필요하며, 확장 프로그램 설치만으로 사내 정보에 접근할 수는 없습니다.

현재 배포 상태

웨일 게시·설치 확인: 2026년 10월 26일 · 게시 버전 1.0.10

  • 웨일 스토어: 게시 완료 — 웨일 스토어에서 무료 설치. 압축 해제나 개발자 모드는 필요 없습니다.
  • 엣지: 1.0.10 스토어 심사 중 — 10월 26일 회사 계정 승인 후 심사가 접수되었습니다. 승인·게시 확인 후 설치 링크를 안내합니다.
  • Chrome 웹스토어: 미등록 — 10월 21일 확인 기준입니다.

설치하고 연결하기

NDA의 설치 안내는 웨일·엣지의 배포 상태를 각각 보여줍니다. 현재 설치 가능한 브라우저를 선택하고, NDA와 포탈은 같은 브라우저·프로필에서 사용해 주세요.

스토어 링크는 현재 브라우저의 새 탭으로 열립니다. 웨일이 자동 설치되거나 실행되지는 않습니다. 웨일이 없다면 공식 다운로드 페이지에서 설치한 뒤 웨일로 NDA를 열어 주세요. 엣지는 승인·게시 확인 전까지 설치 버튼이 비활성화됩니다.

  1. 위 웨일 스토어 링크를 열고 ‘추가하기’ → ‘추가’를 눌러 설치합니다.
  2. 같은 웨일 프로필에서 NDA 관리 시스템으로 돌아와 ‘연결 다시 확인’을 눌러 새로고침하고 연결 상태를 확인합니다.
  3. 진행 과정의 4단계에서 ‘기안 작성하기’를 누르고, 제목을 확인하거나 수정한 뒤 ‘기안 자동화 시작’을 누릅니다.
  4. 새 포탈 창에서 필요하면 직접 로그인하고 자동 준비가 끝날 때까지 원래 NDA 탭을 열어 둡니다.
  5. 제목·결재선·참조자·첨부파일을 확인한 뒤 본문 작성과 나머지 처리를 직접 진행합니다.

업로드 시작·임시저장·결재 요청은 자동 실행하지 않습니다.

기존 설치본과 중복 설치 확인

이전 버전이나 폴더로 직접 설치한 확장이 있다면 진행 중인 기안을 마친 뒤 웨일 확장앱 목록에서 이전 설치본을 삭제하고 위 스토어 링크로 새로 설치하세요. 새 등록은 이전 설치본에서 자동 업데이트되지 않습니다. 이미 v1.0.10으로 연결된다면 다시 설치할 필요가 없습니다. 스토어 개발자센터의 등록은 삭제하지 마세요.

‘설치 상태 확인 필요’는 이전 버전의 응답만 감지되어 현재 설치 상태를 확정할 수 없다는 뜻입니다. 삭제·비활성화 후에는 NDA 페이지를 새로고침하세요. 스토어 설치본을 삭제했어도 같은 이름의 직접 설치본이 켜져 있으면 계속 응답할 수 있습니다.

연결이 안 될 때

  • 확장이 현재 브라우저·프로필에서 켜져 있는지 확인한 뒤 NDA 페이지의 ‘연결 다시 확인’을 눌러 새로고침합니다.
  • 회사 정책으로 설치나 사이트 접근이 차단되면 사내 브라우저 관리 담당자에게 확인합니다.
  • 직원을 확정하지 못하거나 입력 중 오류가 발생하면 표시된 안내를 확인합니다. 설정을 정정한 뒤 NDA에서 새 작업을 시작합니다.
  • 포탈 창을 실수로 닫았다면 NDA의 ‘기안 자동화 시작’을 다시 누릅니다. 이전 창의 미저장 내용은 새 창으로 옮겨지지 않습니다.

지원 문의

사내 NDA 관리 담당자 또는 AI솔루션팀으로 문의해 주세요. 사용 브라우저·확장 버전·오류 문구를 함께 알려주면 확인에 도움이 됩니다. 문의에 비밀번호나 계약 문서 원문을 넣을 필요는 없습니다.
