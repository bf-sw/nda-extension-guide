NDA 기안 결재선 연결

개인정보 처리 안내

시행일: 2026년 10월 20일 · 운영: 바디프랜드 NDA 관리 시스템 운영 담당 부서

이 안내는 ‘NDA 기안 결재선 연결’ 브라우저 확장 프로그램에 적용됩니다. 사용자가 NDA 관리 시스템에서 ‘기안 자동화 시작’을 누르면 새 워크쓰루 기안 화면에 필요한 정보를 준비합니다.

처리하는 정보와 목적

  • 기안자·결재자·합의자·참조자의 이름, 업무 이메일, 부서, 직책, 포탈 직원 식별자: 기안자와 대상 직원을 확인하고 결재선·참조자를 입력합니다.
  • 프로젝트명, 협력사명, 기안 제목, 기안 본문 기본값(사용자가 확인·수정한 법무 의견과 별첨 파일명 포함), 결재 순서·방법: 사용자가 확인한 내용으로 기안 화면을 준비합니다. 본문은 포탈 편집기가 비어 있을 때만 넣습니다.
  • 해당 프로젝트의 NDA 작성본·법무의견서 내용, 파일 식별자·이름·크기·형식·검증 해시: 정확한 두 파일을 확인하여 포탈 첨부 목록에 추가합니다.
  • 연결된 탭 식별자, 작업 식별자, 시작 시각, 처리 단계와 오류 내용: 다른 기안과 혼동하지 않고 진행 상태를 안내합니다.

정보를 읽고 전달하는 범위

확장은 NDA 관리 시스템(nda.bodyfriend.co.kr)과 워크쓰루 포탈(portal.bodyfriend.co.kr) 두 사이트에서만 동작합니다. 사용자의 기존 로그인 상태로 NDA 정보와 파일을 HTTPS로 읽어, 사용자가 시작한 포탈 기안 화면에 전달합니다.

비밀번호나 로그인 쿠키 값을 읽거나 별도로 저장하지 않습니다. 확장 자체에는 광고, 외부 분석 서비스, 일반 웹 방문 이력 수집 기능이 없습니다. 업무 정보와 문서를 판매하거나 광고·신용 평가에 사용하지 않으며, 기안 준비와 무관한 외부 서비스로 보내지 않습니다.

파일 내용의 보관과 해제

파일 내용은 NDA 탭 메모리에 일시 보관합니다. 준비 완료·오류·NDA 페이지 새로고침·다른 주소로 이동·닫기 또는 최대 10분의 연결 시간이 끝나면 NDA 탭의 보관본을 해제합니다. 포탈 첨부 목록에 이미 추가한 파일과 입력 내용은 사용자가 검토할 수 있도록 포탈 화면에 남습니다.

확장은 업로드 시작·임시저장·결재 요청을 실행하지 않습니다. 사용자가 내용을 확인한 뒤 포탈에서 직접 처리합니다.

작업 정보의 보관과 삭제

직원 정보, 기안 제목, 첨부 메타데이터와 진행 상태는 브라우저의 세션 저장소에 임시 보관합니다. 작업 시작 후 10분이 지나면 재사용하지 않으며, 이후 새 작업을 시작할 때 만료 정보를 정리합니다. 해당 NDA 탭 또는 연결된 포탈 탭을 닫으면 관련 작업 정보를 삭제하고, 브라우저 세션이 끝나면 세션 저장소 정보가 사라집니다.

기존 NDA 원본과 사용자가 포탈에서 직접 저장·업로드·결재 요청한 자료는 각 사내 시스템의 보관 정책에 따릅니다. 확장을 삭제해도 원본 문서나 이미 저장된 기안은 삭제되지 않습니다. 이 안내는 사내 시스템 자체의 접근 로그와 문서 보관 정책을 대체하지 않습니다.

이 안내 웹사이트

이 안내 웹사이트는 GitHub Pages에서 제공합니다. GitHub는 보안을 위해 방문자의 IP 주소를 기록·보관합니다. 자세한 내용은 GitHub 개인정보 처리방침에서 확인할 수 있습니다. 확장이 처리하는 직원 정보와 NDA 문서를 이 안내 웹사이트로 전송하지 않습니다.

사용 중지와 문의

포탈 안내의 입력 중지 기능으로 자동 입력을 중지할 수 있습니다. 브라우저 확장 관리 화면에서 확장을 끄거나 삭제할 수도 있습니다.

직원 정보·원본 문서의 조회, 정정, 삭제 또는 확장 프로그램의 정보 처리에 관한 문의는 사내 NDA 관리 담당자 또는 AI솔루션팀에 요청해 주세요. 스토어 배포 후에는 해당 확장 프로그램의 개발자 연락처로도 문의할 수 있습니다.
